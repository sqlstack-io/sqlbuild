SQLBuild uses adapters to connect to different database engines. Snowflake is the main target.

- **Supported:** ready for production use.
- **Beta:** builds, tests and plans work, but with less production use so far. Expect rough edges, and please [report issues](https://github.com/sqlstack-io/sqlbuild/issues).

| Adapter | Status | Install |
|---------|--------|---------|
| [Snowflake](/docs/concepts/adapters/snowflake) | Supported | `sqlbuild[snowflake]` |
| [DuckDB](/docs/concepts/adapters/duckdb) | Supported | included by default |
| [MotherDuck](/docs/concepts/adapters/motherduck) | Supported | included by default (uses DuckDB) |
| [PostgreSQL](/docs/concepts/adapters/postgres) | Supported | `sqlbuild[postgres]` |
| [BigQuery](/docs/concepts/adapters/bigquery) | Beta | `sqlbuild[bigquery]` |
| [Databricks](/docs/concepts/adapters/databricks) | Beta | `sqlbuild[databricks]` |
| [SQL Server](/docs/concepts/adapters/sqlserver) | Beta | `sqlbuild[sqlserver]` |
| [SQLite](/docs/concepts/adapters/sqlite) | Beta | included by default |
| [ClickHouse](/docs/concepts/adapters/clickhouse) | Beta | `sqlbuild[clickhouse]` |
| Redshift | Planned | |
| Trino | Planned | |
| Spark | Planned | |
| Athena | Planned | |

Set the adapter in `sqlbuild_project.toml`:

```toml
name = "my_project"
adapter = "duckdb"
```

Or override it per developer in `sqlbuild_local.toml`:

```toml
adapter = "duckdb"
```

## Custom adapters

To extend a built-in adapter or add another database engine, see
